# Neko

Classic desktop cat sprites used by BIUM Mini / Home agent.

- Sheet: [`assets/neko.png`](https://github.com/crgimenes/neko/blob/master/assets/neko.png) from [crgimenes/neko](https://github.com/crgimenes/neko) (**BSD-2-Clause**)
- Grid: **8×4** tiles of **32×32** (oneko layout)
- Layout reference: [adryd325/oneko.js](https://github.com/adryd325/oneko.js)

Upstream notes that sprites follow the classic Neko / oneko tradition; this Go reimplementation does not include original source code beyond sprites/sounds.
